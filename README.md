# ✅ Minhas Tarefas

Aplicativo PWA (Progressive Web App) para gerenciamento de tarefas com foco em atendimento de campo, desenvolvido para uso diário com funcionalidades de localização, compartilhamento e gerenciamento de dados.

## 📱 Acesse o App

🌐 **Link Online:** [https://abl0n.github.io/appTarefas/](https://abl0n.github.io/appTarefas/)

---

## ✨ Funcionalidades

### 📋 Gerenciamento de Tarefas
- Criar, editar e excluir tarefas
- Marcar tarefas como concluídas/pendentes
- Reordenar tarefas por drag & drop
- Filtrar por: Todas, Pendentes, Concluídas
- Nº Ordem e Observações por tarefa

### 📍 Endereços e Localização
- Busca de endereços via OpenStreetMap (Nominatim)
- Botões integrados para **Google Maps** e **Waze**
- Endereço completo com CEP, bairro, cidade, estado

### 🔄 Compartilhamento e Backup
- **📤 Exportar Dados:** Salva todas as tarefas em arquivo JSON
- **📥 Importar Dados:** Carrega tarefas de arquivo JSON
- **📦 Arquivar Concluídas:** Remove da lista e salva em backup
- **🔄 Reset App:** Restaura estado inicial
- **🗑️ Limpar Dados:** Remove todas as tarefas mantendo perfil

### 📱 PWA (Progressive Web App)
- Instalável na tela inicial do celular
- Funciona offline (dados salvos localmente)
- Ícone personalizado
- Tela cheia (sem barra de navegação)

### 🎨 Temas
- **Modo Claro** (padrão)
- **Modo Escuro** (com alternância via menu)
- Salva preferência no localStorage

### 📤 Compartilhamento
- **WhatsApp:** Compartilha lista de tarefas formatada
- **QR Code:** Link de acesso rápido

### 📊 Estatísticas
- Total de tarefas
- Tarefas concluídas
- Tarefas pendentes
- Tarefas com endereço
